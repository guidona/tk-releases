# Security

If you find a security problem in tk (a way for a file, a repository, a website or another program to
run code, read your files or reach your credentials through tk), please report it privately:
[open a private security advisory](https://github.com/guidona/tk-releases/security/advisories/new).
Only the maintainer sees it. Please don't open a public issue for it.

Say which version you run, what an attacker controls and what they get, and how to reproduce it. You'll
get an answer, and credit in the release notes once it's fixed, if you'd like.

# tk

tk is a terminal for Linux built around AI coding agents: agent tabs and an agents board, a file
viewer with diffs and blame, a Git view, an Explorer, notes, workflows and a managed zsh setup, in
one window.

**This repository holds no code.** tk's source is private. This is where you:

- **Report a problem** or **suggest something**: [open an issue](../../issues/new/choose). In tk,
  **Report a problem** (in the tk menu) fills one in for you, with the details that help.
- **See what changed**: the [releases](../../releases) list each version's notes, and
  [CHANGELOG.md](CHANGELOG.md) has them all.
- **Read how tk treats your data**: [PRIVACY.md](PRIVACY.md). In short: tk sends nothing about you
  anywhere; a report goes out only when you submit it yourself.
- **Report a security issue privately**: see [SECURITY.md](SECURITY.md). Please don't open a public
  issue for it.

## Before you open an issue

- Check whether someone already reported it: [search the issues](../../issues?q=is%3Aissue).
- Say which version you run (tk menu → About) and what you did, what you expected and what happened.
- Issues are public. tk masks your home folder, emails and tokens in its log, and shows you
  everything a report holds before it goes anywhere, but read it once more before you submit.
